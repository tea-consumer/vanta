# Experimental patches

Nothing in this folder ships unless a build names it in `VANTA_EXPERIMENTAL`
(see `docs/building.md`). A patch's prefs go in a `.js` file with the same
name. Once a patch is confirmed, it moves into `patches/` and its prefs into
the patch or `prefs/vanta.js`.
